# Kişisel katkı dosyaları

Her üye kendi branch'inde bir katkı dosyası oluşturup kendi PR'ına ekler.
Dosya adı hocanın istediği biçimde olmalıdır:

`AD_SOYAD_OGRENCI_NUMARASI_GITHUB_KULLANICI_ADI.md`

Örnek: `HASAN_KAYA_230123123_hasankayyya.md`.
Bu örnek bir ekip üyesi veya yapılmış katkı kaydı değildir.

Aşağıdaki şablonu kendi dosyanıza kopyalayın. Yalnızca gerçekten tamamladığınız
işleri yazın; planlanan işleri tamamlanmış gibi göstermeyin. Ortak başlangıç
altyapısını bireysel katkınız olarak sahiplenmeyin. Hoca dosyanın yanında
GitHub'daki gerçek değişikliklerinizi de inceleyecek.

```markdown
# Ad Soyad — Öğrenci numarası

GitHub kullanıcı adı:
Sorumluluk:

## Tamamladığım işler

- Değiştirdiğim/eklediğim dosya, yaptığım işlem ve gerekçesi:

## Doğrulama ve deneyler

- Çalıştırma komutu:
- Kullanılan veri bölümü ve varsa dataset_summary_sha256:
- Sonuç ve üretilen çıktı dosyası:
- Bulgular ve sınırlamalar:

## GitHub kanıtı

- Kendi commit bağlantılarım:
- Kendi PR bağlantılarım:

## Sunuma katkım

- Hazırladığım açıklama, slayt veya sonuç:
```
